# FileManager

Консольный файловый менеджер на C# (.NET 8) с SQLite.
Семестровое задание по дисциплине «Разработка безопасного программного обеспечения».

## Возможности
- Сведения о дисках и файловой системе
- Чтение, запись и удаление файлов
- Работа с JSON и XML
- Создание и безопасное извлечение ZIP-архивов
- Регистрация и вход (PBKDF2), журнал действий в БД

## Защита
Path Traversal, SQL-injection, XXE, небезопасная десериализация, Zip Slip, Zip Bomb.

## Запуск
Требуется .NET 8 SDK.

    dotnet restore
    dotnet run
